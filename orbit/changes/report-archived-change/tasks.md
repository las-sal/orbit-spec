## 1. Shared resolver

- [x] 1.1 Move `findArchivedDir` (and its `escapeRegExp`) from `src/core/emit-composition.ts` into a new `src/core/archived-change.ts`, exported; `emit-composition.ts` imports it. Its behaviour is unchanged except that only entries that RESOLVE to a directory match, symbolic links followed (`fs.statSync`, never the directory entry's own type) — a regular file of a matching name is skipped before the lexical selection, and a symlinked entry is admitted so the containment check can refuse it — a correction the emit surface inherits (design D1).
- [x] 1.2 Unit tests for the resolver (symlink cases skip where the platform cannot create a symlink, as on an unprivileged Windows runner): no archive root → null; no match → null; two dated matches → the lexically greatest; a name containing regex metacharacters matches literally; a sibling whose name only ends with `-<name>` after another hyphenated word does not match unless the date prefix is exact; a regular file `2026-02-01-<name>` beside a directory `2026-01-01-<name>` resolves to the directory; only a regular file → null; a symlink to a directory is returned (the caller's containment check decides it).
