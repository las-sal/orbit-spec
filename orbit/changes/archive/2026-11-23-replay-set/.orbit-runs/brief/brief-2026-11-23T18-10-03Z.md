## What was built

A replay set in this repository, never shipped: a script Sal starts that runs orbit's six default lifecycle commands (explore, propose, apply, the system review, the walk, archive) as real billed Claude Code sessions, each in a small throwaway project prepared at the state just before that command, three times each by default, and grades every session only by what orbit itself printed or wrote during that session. A run that is stopped part-way still keeps its record and stops the session it was running. A second script compares two such runs, says whether a cut is no worse than the baseline, and warns when the two runs' sessions loaded different skills, noting the skills each side loaded that are not orbit's. The checks that cost nothing run in npm test. CI now also checks the generated skills with Claude Code's own validator, pinned to one version.
