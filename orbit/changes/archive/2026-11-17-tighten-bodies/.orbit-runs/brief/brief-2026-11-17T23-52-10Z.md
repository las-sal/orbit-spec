## New terms

- **R-crc-14's mirror corollary**: A ruling Sal made in an earlier program: a skill body may copy a spec's text only if the copy says it is a copy and names the requirement that owns it, a test keeps the copy identical to that requirement's text, and the copy adds nothing to it. (defined in stop-2026-11-17T23-48-04Z.json)
- **decision-writing bullet**: The paragraph in every skill's list of working disciplines that says when the agent writes a stop record, a resolution or a ledger entry. (defined in stop-2026-11-17T20-32-21Z.json, stop-2026-11-17T23-48-08Z.json)
- **line limit**: The maximum number of lines a skill's main file may have, checked by a test in the suite. (defined in stop-2026-11-17T20-32-21Z.json)
- **list of ledger areas**: The bullet's list of the eighteen kinds of decision (what the user sees, defaults, secrets and the rest) after which the agent writes a ledger entry. (defined in stop-2026-11-17T23-48-08Z.json)
- **mirror note**: The sentence in a skill body, before a copied table or grammar, saying that the text is a copy of a requirement in one of orbit's own specs and naming that requirement. (defined in stop-2026-11-17T23-48-04Z.json)
- **reference file**: A file beside a skill that the agent reads only when the skill tells it to, so its text costs nothing until then. (defined in stop-2026-11-17T23-48-08Z.json)
- **stop-condition explanations**: The short gloss the bullet gives beside each of the five situations in which the agent writes a stop record before asking the user. (defined in stop-2026-11-17T23-48-08Z.json)
