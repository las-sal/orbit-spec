## Why

`greet.js` always greets the world. A user who runs it wants to be greeted by name.

## What Changes

- `node greet.js <name>` prints `Hello, <name>!`.
- With no argument the script prints `Hello, world!` as before.

## Capabilities

### New Capabilities

(none)

### Modified Capabilities

- `greeting`: the script greets the name it is given.

## Impact

- `greet.js` and `README.md`.
