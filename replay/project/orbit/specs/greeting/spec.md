# greeting Specification

## Purpose
What `greet.js` prints when it is run.
## Requirements
### Requirement: The script prints a greeting

Running `node greet.js` SHALL print `Hello, world!` on one line and exit 0.

#### Scenario: Run with no arguments

- **WHEN** `node greet.js` is run with no arguments
- **THEN** it prints `Hello, world!` and exits 0
